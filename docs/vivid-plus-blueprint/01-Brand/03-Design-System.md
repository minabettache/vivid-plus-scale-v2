# VIVID+ Design System

## Design Direction

VIVID+ uses a premium dark interface built around purple, violet, black, white, and subtle glass effects.

Gold is not part of the main visual identity.

The customer app, employee app, owner portal, and platform admin must feel like the same brand while serving different purposes.

## Typography

Use one modern sans-serif font family across the platform.

Recommended font: Inter.

Headings must be bold and clear.

Body text must remain easy to read.

Avoid overly small text.

---

## Spacing

Use consistent spacing based on an 8-pixel system.

Examples:

8px

16px

24px

32px

48px

---

## Corners

Small controls: 10px

Buttons: 12px

Cards: 16px

Premium feature cards: 20px

---

## Buttons

Primary buttons use a purple gradient.

Secondary buttons use a dark surface with a visible border.

Danger buttons use red only for destructive actions.

Buttons must have clear hover, pressed, loading, and disabled states.

---

## Cards

Cards use dark surfaces, soft borders, subtle shadows, and limited glass effects.

Avoid excessive blur.

Important information must remain readable.

---

## Icons

Use one icon library across the platform.

Recommended library: Lucide.

Icons must support the label, not replace important labels.

---

## Motion

Animations must be smooth and purposeful.

Use animation for:

- Page transitions
- Points earned
- Reward unlocks
- QR interactions
- Loading states
- Notifications
- Success confirmations

Avoid unnecessary animation that slows the user down.

---

## Accessibility

Maintain strong contrast.

Support keyboard navigation in web portals.

Use visible focus states.

Use large tap targets on mobile.

Do not communicate status using color alone.

---

## Design Rule

Every screen must feel premium, fast, clear, and unmistakably VIVID+.
